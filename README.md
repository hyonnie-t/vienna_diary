# vienna_diary

세계사 주제30 「1815~1848 역할 일기」 웹앱 (2학년, 교과서 150~153쪽).

- 파일: `index.html` / `style.css` / `data.js`(카드·힌트·낱말 풀이) / `app.js`(로직). 빌드 단계 없음.
  `focus_guard.js`·`draft_guard.js`·`glossary.js`는 history26 `snippets/`에서 복사한 것(47ed621 시점).
- 미리보기: `?preview=1` (저장 없음, 카드도 기억하지 않아 새로고침하면 다시 뽑힘). 자동채움: `?sid=20512&name=이름`.
- 흐름: ① 뽑기(카드 2장 뒤집기 → 1장 선택) → ② 사실 고르기(1개) → ③ 쓰기(칸 3개, 힌트 토글) → ④ 마무리(일기 합본, 제출·글 복사·패들렛 링크).
- 재뽑기 없음: 뽑은 카드는 학번별 localStorage(`vienna_diary:<GAME_NAME>:<학번>`)에 남아 새로고침해도 같은 카드가 나온다.
- 포털 커리큘럼 관리에 activity id 하나 등록: `30차시_역할일기_1815_1848` (`app.js`의 `CONFIG.GAME_NAME`).
- 저장은 기존 기본 제출 경로를 쓰며 백엔드·시트 구조 변경 없음. `reflection`(G열) = ①②③ 합본, `choiceSummary` = 역할 / 고른 사실.
- 패들렛 링크는 백엔드 `?mode=curriculum`의 학년별 포트폴리오 링크를 불러온다(반 정보가 든 링크라 레포에 적지 않는다).
- 카드 문구는 교과서 본문과 쪽수까지 맞춘 것이라 바꾸지 않는다. 바꿔야 하면 효니에게 먼저 묻는다.
